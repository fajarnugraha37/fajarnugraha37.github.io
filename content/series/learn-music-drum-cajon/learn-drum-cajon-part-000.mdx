# Part 000 — Daftar Isi, Target Skill, dan Kontrak Belajar

## Status Seri

- Seri: `learn-drum-cajon`
- Part: `000`
- Topik: Daftar isi, target skill, scope, dan kontrak belajar
- Target akhir seri: mampu mengiringi penyanyi dengan drum dan/atau cajon secara stabil, musikal, dan sadar konteks
- Status: index / pembuka seri

---

# Tujuan Seri

Seri ini disusun berdasarkan pendekatan *The First 20 Hours* oleh Josh Kaufman: bukan untuk menjadi profesional dalam 20 jam, tetapi untuk mencapai kemampuan awal yang usable dengan deliberate practice yang terstruktur.

Target utamanya:

> mampu mengiringi penyanyi dengan drum dan/atau cajon pada lagu sederhana, dengan tempo cukup stabil, groove dasar, dynamics, fill aman, song form awareness, dan vocal-first mindset.

---

# Konteks Learner

Materi ini ditulis untuk learner dengan latar software engineer yang cenderung berpikir deterministic dan sistematis. Karena itu, materi memakai banyak mental model seperti:

- rhythm sebagai clock,
- groove sebagai event loop,
- fill sebagai state transition,
- song form sebagai state machine,
- recording sebagai observability,
- practice log sebagai feedback loop,
- error model sebagai debugging system.

# Kontrak Belajar

Gunakan seri ini dengan prinsip:

1. Jangan hanya membaca; praktikkan.
2. Rekam latihan sesering mungkin.
3. Jangan mengejar fill sebelum time stabil.
4. Jangan menutup vokal.
5. Jangan malu menyederhanakan.
6. Gunakan chart.
7. Pilih 3 lagu capstone.
8. Ubah error menjadi correction drill.
9. Setelah 20 jam, lanjutkan berdasarkan error utama.
10. Tujuan utama: membuat penyanyi dan lagu terdengar lebih baik.
